# Gestor de Finanzas

Aplicación web de finanzas personales multi-moneda (PEN, USD, EUR) con React, TypeScript, Tailwind y Recharts.
Los datos se guardan en el navegador de cada persona (localStorage).

## Publicar en GitHub Pages

1. Sube todo el contenido de esta carpeta a la rama `main` de tu repositorio (incluida la carpeta `.github`).
2. En el repositorio ve a **Settings → Pages** y en **Source** elige **GitHub Actions**.
3. Cada vez que subas cambios a `main` se publica solo. El enlace queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Ejecutar en tu computadora

```bash
npm install
npm run dev
```
